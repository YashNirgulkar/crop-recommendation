Minor Project Architecture & Viva Q&A Guide

Complete project synopsis, system architecture, and frequently asked Viva examination questions with answers.

01

Project Abstract & Motivation

Agriculture is the backbone of the economy, yet traditional crop selection often relies on subjective intuition or outdated seasonal patterns. AgroAI leverages ensemble supervised machine learning (Random Forest Classifier with 100 decision trees) trained on multi-attribute agricultural data to scientifically predict the most suitable crop with 99.55% accuracy, accompanied by exact fertilizer dosage calculations, live meteorological synchronization, and RAG document intelligence.

02

End-to-End System Architecture

1. Data Ingestion 2,200 Benchmark records across 22 crops
2. Preprocessing Scaling, encoding, stratified splitting
3. Multi-Model ML Random Forest, SVM, GB benchmark
4. RAG AI Agent Document vector search & LangChain agent
5. Modern UI Planet-friendly aesthetic dashboard
03

Top Viva Examination Questions & Answers

Q1: Why did you choose Random Forest over a single Decision Tree?
Answer: A single Decision Tree is prone to high variance and overfitting on non-linear soil-climate boundaries. Random Forest constructs an ensemble of 100 decorrelated decision trees using bootstrap aggregating (bagging) and random feature subspace selection, achieving 99.55% test accuracy.
Q2: How does the RAG Document Assistant work?
Answer: The RAG (Retrieval-Augmented Generation) pipeline parses uploaded agricultural PDF research papers, splits them into semantic text chunks using `RecursiveCharacterTextSplitter`, indexes them in an in-memory vector store, and retrieves context to generate cited answers via Groq / OpenAI LLMs or the local agronomy inference engine.
Q3: How does the Fertilizer Doctor calculate dosages?
Answer: It calculates stoichiometric nutrient deficits ($\Delta N, \Delta P, \Delta K$) against optimal agronomy thresholds, converting deficits to commercial fertilizer weights (DAP $18\% N, 46\% P_2O_5$, Urea $46\% N$, MOP $60\% K_2O$) in kg/acre with split schedules.
